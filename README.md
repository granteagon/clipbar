# ClipBar (working name)

A small, native macOS clipboard history app built with Swift, AppKit, and SwiftUI. Free and MIT licensed. macOS 13 or newer. No third-party packages, network requests, analytics, accounts, or cloud sync.

**Naming status:** ClipBar is already used by unrelated clipboard apps. This implementation is independent; the public name is pending a decision.

## Use

Build with `./scripts/build.sh`, then open `dist/ClipBar.app`. The local build is ad-hoc signed for development; it is not a notarized public release.

- Press **Command-backslash** or click the clipboard menu bar icon.
- Search, use arrow keys to choose an entry, and press Return to copy it. The previous app regains focus; press Command-V to paste.
- Press **Command-comma** while history is open to access Settings. Native toolbar panes organize General, History, Privacy, and Shortcuts.
- General → **Show icon in menu bar** is on by default. Turn it off for keyboard-only access with no Dock or menu bar icon. Reopen ClipBar from Finder or Spotlight to recover access; a failed shortcut registration automatically restores the menu bar icon.
- Settings offers Command-slash and Command-Shift-V alternatives. A conflicting shortcut is reported; the menu bar icon still works.
- Capture plain text and PNG/TIFF images. Rich formatting and file objects are not preserved.
- Pause capture, delete individual entries from their context menu, or clear history.
- To start automatically, add the built app in System Settings → General → Login Items.

## Privacy defaults

| Setting | Default |
| --- | --- |
| Maximum history | 50 entries (configurable 1–500) |
| Age limit | 24 hours (0 disables expiry) |
| Save across restarts | Off; history lives in process memory |
| Clear when locking/sleeping | On |
| Maximum entry / total payload | 4 MiB / 32 MiB |
| Network and telemetry | None |

Optional persistence uses AES-GCM encryption, a random 256-bit key stored in the login Keychain, and a local file under `~/Library/Application Support/ClipBar/history.enc`. Turning persistence off deletes that file. Deleted data is not a forensic secure-erase guarantee; filesystem snapshots, backups, and OS memory management are outside the app's control.

Copies marked `org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`, or the 1Password marker are ignored. Common password manager bundle IDs are excluded by default; edit the list in Settings. Exclusion uses the foreground app as a best-effort source signal. **Unmarked passwords and other secrets cannot be reliably recognized.** Lock/sleep clearing clears ClipBar history, not the system clipboard. Settings includes a separate command to clear both.

The app polls the system clipboard every half-second and captures changes after launch. Very fast consecutive copies may be missed. Other apps, Universal Clipboard, or Spotlight may independently retain the system clipboard; ClipBar does not control their storage. This is not a data-loss-prevention product. Work installation requires your organization's approval.

## Managed devices

IT administrators can enforce capture, count, expiry, persistence, lock clearing, exclusions, and shortcuts with a macOS configuration profile. Forced controls are disabled in Settings; the app refreshes policy approximately every two seconds. See [deployment documentation](docs/DEPLOYMENT.md) and the [example profile](docs/ClipBar.mobileconfig).

## Development

```sh
swift test
./scripts/build.sh
open dist/ClipBar.app
# Universal Apple Silicon + Intel build:
./scripts/build.sh --universal
```

Open `Package.swift` in Xcode to develop. Swift 5.9+ and the macOS SDK are required. Tests exercise expiry, deduplication, limits, eviction, encrypted persistence, and tamper rejection. See [manual validation](docs/TESTING.md) for OS integration checks.

## Distribution

GitHub publication and Homebrew packaging are pending the public-name decision. A Developer ID Application certificate and Apple notarization credentials are required for the intended public release. See [release instructions](docs/RELEASING.md). Homebrew's central cask repository has its own acceptance requirements; a personal tap is the initial distribution route.
